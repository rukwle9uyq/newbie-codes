# 🔄 回文字符串判断

判断一个字符串是不是回文（正读反读都一样）。提供两种实现方法，方便对比学习。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- 输入任意文字，判断是不是回文
- 自动忽略大小写和空格
- 两种实现方法同时验证结果
- 是回文的话会显示反转后的样子
- 可以连续判断多次

## 💡 知识点

- 字符串切片 `s[::-1]` 反转字符串
- 字符串方法：`.lower()`, `.replace()`
- `len()` 求字符串长度
- 双指针思路：左右两端同时往中间走
- `while` 循环和条件判断
- 两种方法对比，理解 Python 的简洁写法和底层原理

## 📝 学习思路

1. 先理解回文的定义：正读反读一样
2. 最简单的方法：把字符串反转，和原字符串比较
3. 进阶方法：用两个指针从两头往中间比，遇到不一样就不是回文
4. 预处理很重要：忽略大小写和空格，判断更智能
5. 可以尝试加上"忽略标点符号"的功能，或者找一段文字里最长的回文子串
