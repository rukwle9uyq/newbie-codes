# 📊 词频统计器

统计一段英文文本中每个单词出现的频率，并按次数排序显示。

## 🚀 运行方法

```bash
python main.py
```

然后输入英文文本，空行结束。

## 📖 功能说明

- 支持多行输入（空行结束）
- 自动忽略大小写（Hello 和 hello 算同一个）
- 自动去掉标点符号
- 统计总单词数、不同单词数
- 按出现次数从多到少排序
- 显示前20个高频词及占比

## 💡 知识点

- `string.punctuation` 所有标点符号
- `str.lower()` 转小写
- `str.replace()` 替换字符
- `str.split()` 分割字符串
- 字典 `dict` 的使用（键值对）
- `sorted()` 排序函数，`key=lambda x: x[1]`
- `reverse=True` 降序排列
- 字符串格式化对齐

## 📝 学习思路

1. 先理解字典的概念：键是单词，值是次数
2. 遍历每个单词，在字典里累加次数
3. 学会用 `sorted()` 对字典按值排序
4. 数据清洗很重要：统一小写、去标点，不然统计不准
5. 可以尝试加上"忽略停用词"功能（比如 the、a、is 这些太常见的词不算）
