# 🔢 进阶猜数字

猜数字游戏的进阶版，有多种难度、历史记录和统计功能。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- **三种难度**：简单(1-50, 10次)、普通(1-100, 7次)、困难(1-500, 10次)
- **历史记录**：记录每局的猜测次数和胜负
- **统计数据**：总局数、胜利局、平均次数、最少次数
- **输入验证**：输入错误不消耗猜测次数
- 提示大小，帮助玩家逐步缩小范围

## 💡 知识点

- 函数定义和调用 `def yi_ju_you_xi(参数)`
- 函数返回值 `return`
- 列表的追加 `append()` 和列表推导 `[x for x in ...]`
- 内置函数 `sum()`, `min()`, `len()`
- 主菜单 + 游戏函数的代码组织结构
- `isdigit()` 验证数字输入
- 多层条件分支 `if / elif / else`

## 📝 学习思路

1. 先把"玩一局"的逻辑封装成一个函数，主程序只负责菜单
2. 用一个列表 `li_shi` 保存所有局的结果
3. 统计数据的时候用列表推导筛选出胜利的局
4. 输入错误不算次数，体验更好
5. 可以试试加一个"排行榜"功能，或者加双人对战模式
