## 🎯 学习路线

1. 从 ⭐ 难度的项目开始，熟悉基本语法
2. 然后挑战 ⭐⭐ 难度的项目，练习综合运用
3. 每个项目都建议先自己动手写，再看参考代码
4. 完成所有项目后，可以尝试给每个项目加新功能

## 📖 运行环境

- Python 3.8+
- 所有代码均为纯标准库，无需额外安装依赖
- 在终端运行 `python main.py` 即可
