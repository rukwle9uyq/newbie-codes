# ✖️ 九九乘法表

打印九九乘法表的小程序，包含三角形版本和完整方阵版本。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- 打印三角形九九乘法表（经典款）
- 打印完整9×9方阵版本
- 列对齐整齐，美观易读

## 💡 知识点

- 双重循环（外层×内层）
- `while` 循环和 `for` 循环两种写法对比
- `print(..., end=" ")` 不换行打印
- 字符串格式化对齐：
  - `{n:<2}` 左对齐，占2位
  - `{n:>3}` 右对齐，占3位

## 📝 学习思路

1. 先理解"两层循环"的概念：外层控制第几行，内层控制每行的列
2. 三角形乘法表的关键是：内层只循环到外层当前的数（j <= i）
3. 学会用格式化字符串让输出对齐，看起来更专业
4. 对比 `while` 和 `for` 两种写法，体会各自的适用场景
5. 可以试试打印一个倒三角版本，或者打印加法表
