# 🎲 掷骰子模拟器

一个简单好玩的掷骰子小程序，可以同时掷多个骰子，统计总点数和平均值。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- 默认掷1个骰子，也可以输入任意个数
- 显示每个骰子的点数
- 自动计算总点数和平均值
- 多个骰子时，如果全一样（豹子）会有惊喜提示
- 可以一直玩，输入 q 退出

## 💡 知识点

- `import random` 导入随机模块
- `random.randint(1, 6)` 生成1到6的随机数
- `for i in range(n)` 循环 n 次
- 列表的使用，逐个添加元素
- 字符串 `.lower()` 方法
- 判断列表元素是否全部相同的思路

## 📝 学习思路

1. 先学会用 `random.randint` 生成随机数
2. 用循环来掷多个骰子，把结果存进列表
3. 顺便累加总分，最后算平均值
4. 加一点小彩蛋（豹子检测）让程序更有趣
5. 可以尝试加一个"和电脑比大小"的对战模式
