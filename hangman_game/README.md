# 🎮 Hangman 猜单词

经典的 Hangman 猜单词游戏。电脑随机选一个英文单词，玩家逐个字母猜，猜错6次就输了。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- 20个常用简单英文单词随机出题
- 显示当前猜到什么程度（下划线代表未猜出）
- 显示剩余机会和已猜错的字母
- 防止重复猜同一个字母
- 输入验证（只能输入单个英文字母）

## 💡 知识点

- `random.choice()` 从列表中随机选一个
- 列表推导和索引访问 `yi_cai[i]`
- `" ".join(列表)` 把列表拼成字符串
- `in` 关键字判断元素是否存在
- 多层条件判断嵌套
- 游戏主循环设计（显示状态→判断胜负→获取输入→更新状态）

## 📝 学习思路

1. 先规划好游戏循环：显示状态 → 判断结束条件 → 获取输入 → 更新状态
2. 用一个列表 `yi_cai` 来保存当前猜测进度，初始全是下划线
3. 猜对了就把对应位置的下划线替换成字母
4. 猜错了就扣生命值，把字母加到错误列表里
5. 可以尝试给游戏加一个"小人画画"的功能，每错一次多画一笔
