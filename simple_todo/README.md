# 📝 简易待办清单

一个简单的待办事项管理小工具，支持增删改查，数据自动保存到本地文件。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- ✅ 查看所有待办事项（显示完成状态）
- ➕ 添加新的待办
- ✔️ 标记事项为已完成
- 🗑️ 删除不需要的待办
- 💾 数据自动保存到 todo.txt 文件
- 下次打开自动加载之前的待办

## 💡 知识点

- 列表 + 字典的组合使用（每项是字典，存在列表里）
- 函数封装：每个操作一个函数
- 文件读写：`open()`, `readline()`, `write()`, `close()`
- `os.path.exists()` 判断文件是否存在
- `enumerate()` 遍历列表同时获取序号
- `list.pop(index)` 删除指定位置元素
- 数据持久化概念：程序退出后数据不丢失

## 📝 学习思路

1. 先想清楚数据结构：每项待办需要什么信息（内容、是否完成）
2. 每个功能封装成一个函数，主循环只负责菜单分发
3. 学会用文件保存数据，不然每次打开都清零了
4. `todo.txt` 里每行一条数据，用特殊符号分隔状态和内容
5. 可以尝试加"优先级"、"截止日期"等更多属性
