# 🔐 凯撒密码

凯撒密码加密解密小工具。凯撒密码是最简单的加密方法之一，把每个字母向后移动固定位数。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- **加密**：输入明文和偏移量，输出密文
- **解密**：输入密文和偏移量，输出明文
- **穷举破解**：不知道偏移量也没关系，把26种可能全部列出来
- 只处理英文字母，其他字符（空格、数字、标点）原样保留
- 大写小写分别处理

## 💡 知识点

- `ord()` 获取字符的 ASCII 码
- `chr()` 把 ASCII 码转回字符
- `str.isupper()` / `str.islower()` 判断大小写
- 取模运算 `% 26` 实现循环（Z 后面是 A）
- 解密其实就是反向加密（偏移量取负）
- 凯撒密码只有26种密钥，很容易被穷举破解

## 📝 学习思路

1. 先理解ASCII码：每个字母对应一个数字，A=65, a=97
2. 加密就是把字母对应的数字加上偏移量
3. 超过 Z 要循环回来，用取模运算 `% 26` 实现
4. 解密和加密逻辑一样，只是偏移量取负数
5. 可以试试实现更复杂的维吉尼亚密码（多表替换）
