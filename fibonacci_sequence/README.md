# 🔢 斐波那契数列

生成斐波那契数列的小程序。斐波那契数列的特点是：从第3项开始，每一项都等于前两项之和。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- 输入想要的项数，自动生成数列
- 验证输入必须是正整数
- 整齐排列输出，每10个换一行
- 显示最后一项的具体数值

## 💡 知识点

- `input()` 和字符串判断 `isdigit()`
- 列表 `list` 的 `append()` 方法
- `while` 循环累加
- `for` 循环遍历列表
- 字符串格式化 `f"{num:>8}"` 右对齐
- 索引访问 `shulie[-1]` 取最后一个元素

## 📝 学习思路

1. 先搞清楚斐波那契数列的规律：每个数 = 前两个数相加
2. 用一个列表来保存所有数，初始前两项都是 1
3. 用循环从第3项开始逐个算出并追加到列表
4. 打印的时候注意格式对齐，看起来更专业
5. 可以试试用递归的方法来写，看看有什么区别
