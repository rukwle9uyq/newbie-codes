# 🌡️ 温度转换器

一个简单的温度转换小工具，可以在摄氏度和华氏度之间互相转换。

## 🚀 运行方法

```bash
python main.py
```

## 📖 功能说明

- 支持摄氏度 → 华氏度
- 支持华氏度 → 摄氏度
- 可以连续多次转换，选3退出
- 输入错误会提示重新输入

## 💡 知识点

- `input()` 函数获取用户输入
- `def` 定义函数
- `if / elif / else` 条件判断
- `while True` 循环和 `break` 跳出
- `try / except` 异常处理（防止输入非数字）
- 字符串格式化 `f"...{变量:.2f}"`

## 📝 学习思路

1. 先理解两个温度转换的数学公式
2. 把公式写成两个函数，输入值返回结果
3. 用 `while` 循环让程序一直跑，直到用户选择退出
4. 加上 `try/except` 防止用户输入字母导致程序崩掉
5. 可以尝试自己加一个"开尔文温度"的转换功能
